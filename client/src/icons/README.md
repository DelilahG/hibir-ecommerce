# Icons

`src/components/Icon.tsx` ships a small set of line icons drawn for this project on a 24px grid.

To use [Iconly](https://iconly.pro) icons, export the matching icons as SVG from your Iconly account
(the free tier at web.iconly.pro includes the "Light" style) and save each one in `iconly/` using the
names below. A file found here replaces the built-in icon with the same name at build time.
Make sure your SVGs use `stroke="currentColor"` so they pick up the text colour.

search, bag, user, arrowRight, arrowLeft, chevronDown, close, menu, plus, minus, trash, truck,
shield, box, wallet, filter, check, alert, grid, chart, list, tag, logout, image

Iconly's licence does not allow redistributing the original files, so check whether your plan allows
committing them to a public repository.
